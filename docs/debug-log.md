# 调试记录

## 问题 1：画面撕裂，帧率只有 15

**现象**：滑动页面时能看到上下半屏错位。

**排查**：
- 单缓冲时 LVGL 渲染期间 CPU 不能改缓冲，SPI 传输要等
- 40 MHz SPI 传 240×320×2 字节约 38 ms，一帧就 26 FPS 上限

**解决**：
- 改双缓冲：LVGL 画 A 块、DMA 传 B 块
- 缓冲区开 40 行而不是全屏，省 RAM

**结果**：30 FPS 稳定，不撕裂。

## 问题 2：屏幕整体偏色，红色显示成蓝色

**原因**：ST7789 默认 RGB 顺序，这块面板是 BGR。

**解决**：`rgb_ele_order = LCD_RGB_ELEMENT_ORDER_BGR`。
