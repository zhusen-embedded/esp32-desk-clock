# 功耗测试

## 各状态电流

| 状态 | 电流 @ 5V | 功耗 |
|---|---|---|
| 屏幕全亮 + Wi-Fi 常连 | 240 mA | 1.2 W |
| 背光 50% + Wi-Fi 睡眠 | 95 mA | 0.48 W |
| 背光 10% + Wi-Fi 睡眠 | 70 mA | 0.35 W |
| 夜间熄屏 | 22 mA | 0.11 W |

## 优化措施

1. 背光 LEDC PWM 调光，白天 60%，夜间 10%
2. Wi-Fi 开 modem sleep，心跳 60 s
3. 22:00~07:00 自动熄屏，只保留触摸唤醒

## 结论

待机 0.35 W，5V/1A 电源完全够用。
